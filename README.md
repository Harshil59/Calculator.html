# Calculator.html

A simple and responsive calculator built using HTML, CSS, and JavaScript.

---

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculations
- Decimal support
- Delete button
- Reset button
- Keyboard input support
- Responsive design

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

---

## Project Structure

```bash
calculator-project/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

---

## How to Run

1. Download or clone the repository

```bash
git clone https://github.com/your-username/calculator-project.git
```

2. Open project folder

3. Run `index.html` in browser

---

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| 0-9 | Numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| Enter | Calculate |
| Backspace | Delete |
| C | Reset |
